マツバカート 八幡学区 REAL
公開版コミット: 3db5f040ba636f373cfff6eb4088225fcd1e4b0b

ゲーム・地図データ・Three.js・画像素材・地図変換スクリプトを含みます。
実地図コースは dist/index.html?course=real で選択します。
ローカルでの起動: このフォルダで python -m http.server 8000 を実行し、
http://localhost:8000/dist/index.html?course=real を開いてください。
HTMLファイルを直接開くと3Dの読み込みに失敗することがあります。
従来コースも同梱。通信対戦サーバーは含まれていない1人用試走版です。
地理データの出典と推定箇所は REAL_COURSE_NOTES.md と dist/data/README.txt を参照。
